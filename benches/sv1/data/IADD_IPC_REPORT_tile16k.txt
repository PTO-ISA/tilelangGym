DEFINITIONS (consistent both sides)
  Ascend: IADD_tot = SIMT_IADD + SIMT_IADD_I
          IADD/memF = IADD_tot / (LDS+FADD+STS)
          IADD/body = IADD_tot / body   (body = MIX body count)
          IPC_body  = body / VF_cyc
  GPU:    addr ops = IADD*|UIADD*|IMAD*|LEA* from SASS (static) or
          INT_warp = integer_thread/32 from ncu (dynamic; pending reconnect)
          IADD/memF = addr / (LDG|LDS + STS + FADD_warp)

--- 32 el/cyc IPC rooftop (Ascend SimtVF) ---
Fact from opsim: once .64, FADD count = 512 for E=16384 ⇒ E/FADD = 32.
So one SIMT_FADD issue in this counter = 32 elems of work.
Theory max if VF retires 1 FADD/cyc (and matching LDS/STS) ⇒ 32 el/cyc.

Ideal issue mix for that roof (no IADD): {LDS_A, LDS_B, FADD, STS} = 4 issues
for each 32-el quantum ⇒ need IPC ≈ 4.0 sustained (fills 4-issue width).
With IADD tax: body/memF ≈ 1.6–2.0× ⇒ required IPC_body ≈ 4 × (body/memF) / (memF/FADD)
  more simply: cycles_target = E/32 = 512; IPC_needed = body/512.

  TILE2048@T128: body=2008 → IPC_body for 32 el/cyc = 3.92 (4-issue max 4.0); measured IPC=0.395 (10× low); el/cyc=3.22 (9.9× below 32)
  untiled T512: body=2096 → IPC_body for 32 el/cyc = 4.09 (4-issue max 4.0); measured IPC=0.475 (9× low); el/cyc=3.71 (8.6× below 32)

IADD impact: at best tiled, IADD/memF=0.88 (almost +1 addr op per useful op).
Zeroing IADD would cut body ~45% but still need ~IPC 2.2 just for memF@32 el/cyc;
main gap is stall/latency (IPC 0.4 vs 4), not only IADD. 32 el/cyc is the FADD-issue roof,
reachable only if VF is full with the 4-op quartet every cycle.
